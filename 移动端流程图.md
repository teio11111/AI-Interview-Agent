## 四、手机端操作流程

### 步骤 1：把 APK 装到手机
```powershell
# 把 APK 拷到手机（任意方式：QQ/微信/数据线/网盘）
# 手机设置 → 安全 → 允许安装未知来源
# 点击 APK 文件安装
```

### 步骤 2：手机和电脑连同一 WiFi
- 电脑：`<YOUR_LAN_IP>`
- 手机：必须能 ping 通电脑 → `ping <YOUR_LAN_IP>`

### 步骤 3：检查后端在跑
```powershell
python -c "import socket; s=socket.socket(); s.connect(('127.0.0.1',8089)); print('OK')"
```

### 步骤 4：防火墙放行（一次性）
```powershell
# PowerShell 管理员
New-NetFirewallRule -DisplayName "xiaozhi-8089" -Direction Inbound -LocalPort 8089 -Protocol TCP -Action Allow
```

### 步骤 5：手机 App 设置
打开 xiaozhi-unity App → Settings → Application：
- **WebSocket URL**: `ws://<YOUR_LAN_IP>:8089/xiaozhi/v1/`
- **Access Token**: `test-token`
- **Audio Input Sample Rate**: 16000
- **Audio Output Sample Rate**: 24000
- **Opus Frame Duration**: 60

### 步骤 6：测试对话
- 唤醒词或点击对话按钮
- 手机录音 → 客户端编码 Opus → WebSocket 上行
- 服务端解码 → 讯飞转写 → DeepSeek 问答 → Edge 合成语音
- 服务端编码 Opus → WebSocket 下行 → 手机播放
